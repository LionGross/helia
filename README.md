# Helia

**A calm clinical fitness OS for readiness, recovery, and measured training.**

Helia is a modern web app focused on:

- **Readiness & Recovery** – track how ready you are to train
- **Training sessions** – structured workouts with exercise tracking
- **Nutrition & Macros** – food logging and macro targets
- **Polar integration** – heart rate / ECG sessions via BLE
- **Clean clinical UI** – calm, focused design

## Tech Stack

- **TanStack Start** (React Router + Vite)
- **React 19** + TypeScript
- **Tailwind CSS 4**
- **Zustand** for state
- **Better Auth** + PGlite / Postgres
- **Vercel** ready

## Getting Started

```bash
npm install
npm run dev
```

The app runs on `http://localhost:8080`.

## Features

- Home dashboard with readiness, macros, and today's training
- Training session flow with exercise picker
- Nutrition tracking with food database
- Polar heart rate / ECG session viewer
- Local-first data with optional cloud auth
